# 🛠️ Amarin Admin AI

**Консольный AI-агент для администрирования Windows**

Опишите проблему обычным текстом — агент сам продиагностирует и починит систему.

## 💡 Что это

Языковая модель (через **Venice.ai**) планирует действия, а локальные инструменты выполняют их прямо на вашем компьютере: PowerShell, реестр, службы, диски, брандмауэр, `winget` и многое другое.

Программа **не открывает окна настроек** и не отправляет вас в Диспетчер устройств — она делает всё сама и объясняет результат текстом.

> 🔒 Опасные операции всегда требуют подтверждения. Есть режим «только чтение» и откат последнего изменения.

## 🚀 Быстрый старт

**1. Задайте ключ (один раз, навсегда)**

Откройте PowerShell и выполните — подставив свой ключ:

```powershell
setx VENICE_API_KEY "ваш_ключ"
```

Закройте это окно и откройте новое — переменная появляется только в новых процессах.

Проверить:

```powershell
echo \$env:VENICE_API_KEY
```

> ⚠️ Ключ сохраняется в вашем профиле. Не задавайте его так на чужом или общем компьютере.

**2. Распакуйте архив** `Amarin-Admin-AI-win-x64`.

**3. Запустите** `Amarin Admin AI.exe` — двойным кликом или из консоли:

```powershell
cd путь\к\папке\с\exe
.\"Amarin Admin AI.exe"
```

Готово. Введите задачу текстом, например:
> `Почему тормозит система?`
> `Проверь диск C на ошибки`
> `Какие программы можно обновить?`

Проверить инструменты без обращения к API (ключ не нужен):

```powershell
.\"Amarin Admin AI.exe" --smoke-tools
```

## ⌨️ Команды в консоли

Команды со слэшем выполняются локально, без обращения к модели.

| Команда | Действие |
|---|---|
| `/help`, `?` | Справка |
| `/clear` | Очистить историю, журнал, снимки и экран |
| `/session`, `/mode` | Режим: continuous / isolated |
| `/model [имя]` | Показать или сменить модель |
| `/readonly` | Режим только для чтения |
| `/undo` | Откатить последнее изменение |
| `/history` | Журнал выполненных действий |
| `/export [html\|md\|pdf\|all]` | Выгрузить отчёт сессии |
| `balance` | Баланс аккаунта Venice |
| `exit` | Выход |

### Режимы сессии

- 🔗 **Continuous** — агент помнит переписку в рамках сессии.
- 🧩 **Isolated** — каждый запрос обрабатывается с чистого листа.

---

## ⌨️ Команды в чате (окно приложения)

| Команда | Действие |
|---|---|
| `/agent <задача>` | Запускает агента сразу, минуя решение чат-модели. Модель из **Agent (heavy)** |
| `/agent lite <задача>`, `/agent-lite <задача>` | То же, но моделью из **Agent (lite)** |

Агент выполняет задачу полным набором инструментов, а затем обычная чат-модель пишет по его
результату итоговый отчёт — как если бы она сама вызвала `init_agent`. Всё, что не подходит под
эти команды (`/clear`, `C:/agent/...`, текст со слэшем в середине), отправляется модели как
обычное сообщение.

## 🛡️ Безопасность

- ✅ **Подтверждение опасных действий.** Запись в реестр, управление службами, изменения брандмауэра, установка/удаление ПО, очистка диска — только с явного согласия и с описанием, что именно изменится.
- 👁️ **Режим только для чтения** (`/readonly`) блокирует любые изменения — можно спокойно диагностировать.
- ↩️ **Откат** (`/undo`). Перед изменениями снимается снимок служб, задач и реестра. Отдельные операции (правила брандмауэра, компоненты Windows) откатываются вручную — программа честно предупреждает об этом в диалоге.
- 👤 **Защита учётных записей.** Нельзя отключить текущего пользователя или удалить последнего активного администратора.
- 🚫 **Запрет удаления файлов** через PowerShell и filesystem.
- 🔐 **Секреты.** Ключ берётся только из переменной окружения или user-secrets. Ключи BitLocker и пароли пользователей не выводятся.

## ⚙️ Настройки

Файл `appsettings.json` рядом с `.exe` (без секретов):

| Параметр | Описание |
|---|---|
| `Session.Mode` | `continuous` или `isolated` |
| `Venice.Model` | Модель по умолчанию |
| `Venice.MaxToolRounds` | Предел шагов инструментов на запрос |
| `Download.MaxSizeMb` | Лимит размера загрузок |
| `Download.AllowedDomains` | **Только первоначальное заполнение** белого списка при первом запуске |

### 🔒 Белый список загрузок

Скачивание разрешено **только** с доменов из списка (поддомены — тоже). С любого другого домена
`download_file` отказывает, а в чате появляется кнопка «Добавить в белый список».

Рабочий список живёт в `%APPDATA%\Amarin Admin AI\settings.json` (ключ `downloadAllowedDomains`) и
редактируется в **Настройки → Data Controls → Разрешённые источники загрузки**. `appsettings.json`
после первого запуска на него больше не влияет. Пустой список блокирует все загрузки.

### 🎨 Оформление

**Настройки → Appearance**: тема Light / Dark / System (System следует настройке Windows и реагирует
на её смену на лету) и масштаб интерфейса от 80% до 250%.

### 🔔 Уведомление о готовом ответе

**Настройки → Behavior**: карточка внизу справа и звук, когда ответ готов, а окно не на переднем
плане. Карточка держится 15 секунд, показывается на том мониторе, где стоит главное окно, и
закрывается по клику (клик открывает нужное сообщение).

Карточка в углу легко теряется, поэтому одновременно **мигает кнопка на панели задач** — она
мигает, пока вы не вернётесь в приложение, так что пропущенная карточка не значит пропущенный
ответ.

### 👤 Аккаунт

**Настройки → Account**: имя пользователя, изображение профиля, пароль и переключение между
локальными профилями. Аккаунтов в облаке нет — всё лежит на этом компьютере.

У каждого профиля свои чаты и свой `settings.json`. Основной профиль использует
`%APPDATA%\Amarin Admin AI\` — тот же каталог, что и до появления профилей, поэтому обновление
**не переносит и не скрывает существующие беседы**. Дополнительные профили живут в
`%APPDATA%\Amarin Admin AI\profiles\<id>\` и удаляются вместе со своими данными; основной профиль
удалить нельзя.

> ⚠️ **Пароль при запуске блокирует вход в приложение, но не шифрует данные.** Чаты и настройки
> остаются обычными JSON-файлами, доступными для чтения любому, у кого есть доступ к папке.
> Хранится только PBKDF2-SHA256 хеш; восстановить забытый пароль невозможно.

### 🔗 Обмен чатами и экспорт

**Настройки → Data Controls → Обмен чатами по ссылке** включает под ответами ИИ две кнопки:

- **Поделиться** — упаковывает диалог **до этого сообщения включительно** в строку
  `AMRN1:<gzip+base64url>` и кладёт её в буфер обмена. Вставьте её в поиск боковой панели другого
  экземпляра — чат откроется как обычная локальная беседа с полным доступом. Длинный код
  дополнительно сохраняется в `%APPDATA%\Amarin Admin AI\shared\*.amrnchat`.
- **Экспорт** — сохраняет диалог в обычный JSON: все сообщения, вложения и идентификаторы моделей,
  читаемым текстом.

**Настройки → Data Controls → Импорт чата** открывает и `.json`, и `.amrnchat`.

> ⚠️ Ни код, ни JSON **не шифруются**. Любой, кто получит строку или файл, прочитает всю переписку
> вместе с вложенными изображениями.

### 🖼️ Изображения в чате

До 10 изображений на сообщение: перетаскиванием в поле ввода, через `Ctrl+V` или через
**+ → Attach image/document**. Миниатюры появляются над полем ввода, и рамка растёт под них.
Сообщение можно отправить и без текста. Картинки сохраняются вместе с чатом и попадают в экспорт.
Если у выбранной модели нет поддержки vision, рядом с миниатюрами появится предупреждение.

### 📝 Markdown в чате

Ответы модели и ваши собственные сообщения рендерятся полной разметкой: заголовки, жирный и
курсив, зачёркнутый текст, вложенные списки, чек-листы `- [x]`, цитаты, таблицы, ссылки,
горизонтальные линии и инлайн-код. Разметка появляется **по мере печати ответа**, а не рывком в
конце.

Блоки кода получают шапку с названием языка и кнопку копирования, подсветку синтаксиса и
горизонтальную прокрутку для длинных строк (`Shift` + колесо мыши). Подсвечиваются PowerShell,
C#, JSON, XML, SQL, Python, JavaScript/TypeScript, CSS, HTML, Java, C++, F#, PHP и VB; для
остальных языков — просто моноширинный текст. Цвета подсветки берутся из активной темы и
меняются вместе с ней.
