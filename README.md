# Amarin Admin AI

Консольный Windows-админ-агент. Языковая модель (через Venice.ai) планирует действия, а локальные инструменты выполняют их на машине: PowerShell, реестр, службы, диски, брандмауэр, winget и т.д.

Программа не открывает окна настроек и не отправляет вас в Диспетчер устройств — она диагностирует и чинит сама через инструменты, а результат объясняет текстом.

Опасные операции требуют подтверждения. Есть режим только для чтения (`/readonly`) и откат последнего изменения (`/undo`).

## Требования

- Windows 10 или 11 (x64).
- Ключ API Venice.ai.
- .NET на компьютере **не нужен** — релиз self-contained, всё внутри exe.

## Установка ключа (один раз, постоянно)

Программа читает ключ из переменной окружения `VENICE_API_KEY`.

1. Открой PowerShell.
2. Выполни (подставь свой ключ):

```powershell
setx VENICE_API_KEY "твой_ключ"
```

3. Закрой это окно PowerShell и открой новое — переменная появляется только в новых процессах.

Проверить, что ключ задан:

```powershell
echo \$env:VENICE_API_KEY
```

Ключ хранится в профиле твоего пользователя. Не задавай его так на общем или чужом компьютере.

## Запуск

1. Распакуй релизный архив (`Amarin-Admin-AI-win-x64`).
2. Запусти `Amarin Admin AI.exe` — двойным кликом или из консоли:

```powershell
cd путь\к\папке\с\exe
.\"Amarin Admin AI.exe"
```

3. Введи задачу обычным текстом, например: `Почему тормозит система?` или `Проверь диск C на ошибки`.

Проверка инструментов без обращения к API (ключ не нужен):

```powershell
.\"Amarin Admin AI.exe" --smoke-tools
```

## Команды в консоли

Команды со слэшем выполняются локально, без обращения к модели.

| Команда | Действие |
|---|---|
| `/help`, `?` | Справка |
| `/clear` | Очистить историю, журнал, снимки undo и экран |
| `/session`, `/mode` | Переключить режим: continuous / isolated |
| `/model [имя]` | Показать или сменить модель Venice |
| `/readonly` | Режим только для чтения (запись блокируется) |
| `/undo` | Откатить снимок последнего изменения |
| `/history` | Журнал выполненных действий |
| `/export [html\|md\|pdf\|all]` | Выгрузить отчёт сессии |
| `balance` | Баланс аккаунта Venice |
| `exit` | Выход |

## Режимы сессии

- **Continuous** — модель помнит предыдущие сообщения в рамках сессии (история сжимается при росте).
- **Isolated** — каждый запрос обрабатывается с чистого листа, без памяти о прошлых.

Переключается командой `/session`.

## Безопасность

- **Подтверждение опасных действий.** Запись в реестр, управление службами, изменения брандмауэра, установка/удаление ПО, очистка диска и подобное требуют явного подтверждения с описанием, что изменится.
- **Режим только для чтения** (`/readonly`) блокирует любые изменения — можно спокойно диагностировать.
- **Откат** (`/undo`). Перед изменениями снимается снимок служб, задач и реестра, к которому можно вернуться. Отдельные операции (правила брандмауэра, состояние компонентов) откатываются вручную — программа честно сообщает об этом в диалоге подтверждения.
- **Защита учётных записей.** Нельзя отключить текущего пользователя сессии или удалить последнего активного администратора.
- **Запрет удаления файлов** через PowerShell и filesystem.
- **Секреты.** Ключ API берётся только из переменной окружения или user-secrets, в файлах конфигурации не хранится. Ключи восстановления BitLocker и пароли пользователей не выводятся.

## Отчёты

Команда `/export` сохраняет журнал сессии в HTML, Markdown или PDF — со всеми выполненными действиями и их полным выводом.

## Настройки

Файл `appsettings.json` рядом с exe (без секретов). Основные параметры:

- `Session.Mode` — `continuous` или `isolated`.
- `Venice.Model` — модель по умолчанию.
- `Venice.MaxToolRounds` — предел шагов инструментов на один запрос.
- `Download.MaxSizeMb` и `Download.AllowedDomains` — лимиты для загрузок.
