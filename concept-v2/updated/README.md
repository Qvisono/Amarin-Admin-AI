## Материалы

- `references/screenshots/user/` — все 9 исходных изображений без обработки.
- `references/source/` — выборочный снимок UI и связанной логики. Это справочник, не проект для сборки и не разрешение переносить весь код.
- `assets/original/` — исходные XAML-ресурсы иконок, палитры, шрифты и значок приложения.
- `assets/navigation-svg/` — 10 извлечённых контуров разделов настроек, без «Автоматизации»; геометрия исходная, толщина линии задана для мобильного применения.
- `inventory/settings-source.md` — подробная опись исходных контролов настроек с русскими подписями.
- `inventory/ui-controls.csv`, `icon-resources.csv`, `geometry-paths.csv`, `strings-ru.csv` — машиночитаемые описи для проверки полноты переноса.
- `inventory/source-manifest.csv` — пути и SHA-256 снимка исходников; `counts.json` — фактические количества.
- `tools/Collect-References.ps1` — повторное получение материалов из явно заданного исходного каталога. Не запускать без необходимости: повтор заменяет снимок текущими исходниками.
