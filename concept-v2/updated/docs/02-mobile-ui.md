# 02. Детальная спецификация мобильного UI

**Актуальная редакция: концепт 02, `docs/08-concept-v2.md` и `design/mobile-concept.html`. Первая схема отклонена владельцем и убрана в архив.**

Все размеры ниже — логические dp/DIP, не пиксели скриншота. Цифры — проектные значения для проверки на телефоне, а не измерения текущего WPF.

## Система размеров

Базовые поля 16; на ширине 320 — 12. Вертикальные интервалы 4/8/12/16/24/32. Touch target минимум 44×44 на iOS, 48×48 на Android; видимый знак 20–24. Размер видимого фона кнопки не обязан равняться touch target. Текст чата 16, межстрочное расстояние примерно 1.45; подписи 13–14, заголовок страницы 22/semibold. Системный масштаб текста до 200% должен перестраивать строки, а не обрезать их.

| Ширина viewport | Компоновка |
|---|---|
| 320–359 | Composer в два ряда; скрывается logo модели, сохраняются имя/effort; sheet почти на весь экран |
| 360–599 | Телефон: одна колонка, выдвижной sidebar, full-screen настройки |
| 600–839 | Большой телефон/раскладной: та же навигация, колонка сообщений до 720 |
| ≥840 | Допускается постоянный sidebar 320 и контент справа; режим не обязателен для телефона |

Ориентироваться на доступную ширину после insets, а не название устройства. В landscape с клавиатурой уменьшать пустые поля, разрешать scroll страницы и composer, не уменьшать touch targets. При hinge/cutout интерактивные элементы не оказываются под вырезом. Не оборачивать весь экран в общий ScaleTransform.

## CHAT-01. Главный экран

Фон Bg.Window из Amarin. Сверху safe area и компактный header 48: кнопка sidebar слева, название чата одной строкой, без Windows-titlebar, версии, индикатора ПК и журнала. Название — доступная кнопка открытия действий текущего чата. Это навигация, а не дополнительная панель инструментов. Новый чат создаётся в sidebar.

В пустом чате: небольшой оригинальный знак Amarin и «Amarin Chat» в центре свободной области; без персонажа, рекламы и карточек советов. Placeholder ввода «Напишите сообщение…». Если нет ключа, в demo — пометка «Демонстрация» в заголовке/первом информационном состоянии; в production кнопка отправки приводит к объяснению «Добавьте ключ провайдера» и открытию соответствующего экрана.

Лента занимает всё свободное пространство между header и composer. Пользовательские сообщения — сдержанная подложка справа с максимальной шириной около 88%; ответ — читабельная колонка без лишней рамки. Блоки Markdown: заголовки, списки, цитаты, таблицы, ссылки, код, изображения, формулы. Таблица/код скроллится горизонтально внутри своего блока, экран целиком — никогда. Код имеет копирование и опциональные номера строк. Не переносить WPF-рендерер, но сохранить функциональное поведение.

Долгое нажатие на сообщение открывает нижнее меню: копировать, выделить текст, ответить цитатой, изменить собственное сообщение, повторить ответ, поделиться. Недоступные действия не показывать. Ветви после edit/retry сохраняются, под соответствующим сообщением доступны ‹ 2/3 ›; touch targets 48. Стоимость конкретного ответа — в подробностях сообщения, не отдельной постоянно видимой кнопкой в composer. Если reasoning-текст действительно предоставлен сервисом, он может быть свёрнутым блоком; не изображать отсутствующее «размышление».

Автопрокрутка работает только если пользователь уже у нижнего края. Чтение старого ответа не прерывается streaming. Когда появились новые сообщения, компактное временное действие «К последнему» появляется над лентой. Его нет в постоянной панели ввода. При возвращении в чат восстановить позицию и черновик; при открытии нового — нижний край.

## CHAT-02. Composer

Компактная закруглённая поверхность: стандартная высота около 107 dp на iOS / 111 dp на Android при одной строке, radius 26, внешние поля 12. Safe area добавляется только один раз системным layout. Видимые кнопки меньше своих непересекающихся областей нажатия.

Два ряда: многострочный текст (стартовая высота 43), ниже toolbar 44/48. В toolbar: прозрачная кнопка plus 44/48; компактная плашка по ширине содержимого с logo, именем модели и effort в одной строке (`Kimi K2 · High`); общая зона показателей 58×44/48 с контекстом сверху и балансом снизу; отправка в круге 38 с target 44/48. Плашку модели не растягивать фоном на свободную ширину. Отдельного третьего ряда статистики нет.

Два показателя образуют один доступный контрол, открывающий sheet «Контекст и баланс». В screen reader его имя сообщает оба значения. Полная информация крупным текстом в sheet. На 320 dp можно убрать logo модели, оставив его в picker; длинное имя сокращается без скрытия effort. При увеличении системного текста разрешён дополнительный ряд — только по необходимости, не по умолчанию.

Поле ввода растёт с фактическим текстом до 5 строк, затем прокручивается внутри; пустой editor не резервирует эту высоту. Цитата/вложения добавляются условно над текстом. Карточки показывают имя/тип/размер/статус и удаление. Без вложений нет пустого места под них.

В composer только текст, прикрепление, модель + reasoning, контекст, баланс, отправка/остановка. Микрофон, настройки генерации отдельной кнопкой, web search, инструменты, агент, ПК, estimate и библиотека промптов не добавляются. Подробные размеры и visual reference — docs/08.

Отправка неактивна для пустого текста без допустимых вложений. Во время ответа тот же слот становится «Остановить» с квадратом. Прекращение сохраняет уже полученный текст. Double-tap не создаёт второй ход. Enter на мобильной клавиатуре — перенос строки, отправка только кнопкой; IME composition не запускает отправку. После отправки клавиатура остаётся в выбранном пользователем состоянии.

## CHAT-03. Прикрепление

Нижний sheet: «Фото», «Файлы», «Отмена». Камера — опциональная platform capability, только при её реализации и разрешении по действию пользователя. Не добавлять «скриншот рабочего стола». Выбор использует системный picker; приложение получает только выбранные файлы.

Файл проходит состояния picking → preparing → ready / unsupported / failed. Пока preparing, отправка этого набора недоступна. Большое вложение: понятный размер/лимит, возможность убрать; лимит зависит от модели/провайдера, не фиксировать выдуманные 20 MB для всех. Невизуальная модель с картинкой: объяснение и выбор совместимой модели. Ошибка/отмена picker не стирает набранный текст. Удаление вложения из черновика не удаляет оригинал из телефона.

## MODEL-01. Выбор модели и reasoning

Bottom sheet с drag handle; начальная высота около 70%, разворачивается до safe area. Вверху название «Модель», текущий провайдер/ключ, список моделей с исходными логотипами. Поиск закреплён в нижней области sheet над зоной применения, чтобы его легко достать. Фильтры «Картинки», «Код» сохранить как функции каталога. Список прокручивается и виртуализируется.

Строка модели: логотип 24, имя 16, провайдер/контекст/доступная цена в подписи, галочка выбора. Не смешивать деньги и токены в одну величину. Сначала выбранная/избранные, затем каталог с устойчивой сортировкой. «Авто» может сохраняться как выбор одной модели по маршрутизатору; это не агент, но требует настроек и отдельного учёта расходов. В этапе 1 его поведение демонстрируется fake-каталогом.

Нижняя секция «Размышление»: доступные уровни берутся из возможностей конкретной модели, а не универсального списка. Подписи Off/Low/Medium/High и другие только если реально поддерживаются. При несовместимой смене модели выставлять поддерживаемое значение и пояснять изменение. Не переносить запрет `reasoning + tools` из старого ReasoningPolicy: в новом чате tools отсутствуют.

Выбор хранится как черновой до «Применить», отмена возвращает прежний. Изменение во время streaming действует со следующего сообщения; выполняющийся ход сохраняет снимок старой модели/ключа. States: загрузка, каталог из кэша, нет моделей по фильтру, нет ключа («Добавить ключ»), ошибка («Повторить»), провайдер недоступен. Fake-баланс и цена маркируются demo.

## CONTEXT-01 / BALANCE-01

Общий контрол показателей открывает sheet «Контекст и баланс». Его секция контекста содержит: использовано, лимит, резерв ответа, состав (системный пользовательский промпт, инструкции, история, вложения), оценка/точные данные. Пороговые цвета — проектные 70%/90%, дополнены текстом. При неизвестном лимите «Лимит неизвестен», кольцо не даёт ложный процент. Не загружать токенизатор на UI-потоке. Переключение модели пересчитывает лимит. Сжатие требует отдельного осмысленного действия, а не молчаливого удаления истории.

Секция баланса в этом же sheet показывает данные текущего ключа: остаток, валюта/кредиты/токены, источник и время обновления, перейти в «Ключи и траты». Значение неизвестно — «—» и объяснение; ошибка сети — сохранить устаревшее значение с отметкой времени; нулевой баланс — именно 0. Не выдавать расчётный остаток токен-пакета за банковский баланс. Не складывать разные валюты и кредиты.

## NAV-01. Sidebar

На телефоне width = min(360, viewportWidth − 44). Высота до safe area. Поверхность Bg.Sidebar. Остаток чата виден справа под scrim 35–50%; tap по нему закрывает панель. Чат не сжимается в узкую колонку.

Порядок сверху вниз:

- Небольшой знак Amarin и подпись; логотип не дублирует создание чата. Кнопки закрытия нет.
- Компактный фильтр «Все чаты» и гибкая область истории; папки/метки/архив доступны через фильтр.
- **Один нижний ряд:** поле «Поиск», справа квадрат 44×44 (iOS) / 48×48 (Android) с иконкой нового чата. Gap 8. Полной кнопки «Новый чат» над поиском нет.
- Под ним тонкий разделитель и одна строка профиля: аватар 32, имя, шестерёнка справа. Без большой карточки и повторяющейся подписи «Локальный профиль».

Последние две строки закреплены снизу. Новейший чат непосредственно над поиском. Сортировка `LastActivityUtc ASC`, затем стабильный `Id`; открытие чата само по себе не меняет активность. Пустое пространство при небольшом числе чатов находится сверху. Не использовать rotate(180) / перевёрнутые контейнеры: порядок чтения, экранный диктор и координаты должны совпадать с визуальным порядком.

При открытии sidebar показать нижний конец истории. Если пользователь скроллит вверх, обновление чата не вырывает его из места чтения; закрепить якорь по ID/offset. Перестановку активного чата применять после завершения текущего взаимодействия. Загружать старые чаты сверху с сохранением якоря. Поиск показывает найденные беседы в том же порядке, очищение восстанавливает предыдущий scroll. Debounce ~250 ms, отмена устаревшего запроса. «Ничего не найдено» не выглядит как исчезновение всех данных.

Закрепление сохраняется как признак; отдельный фильтр «Закреплённые», без переноса всех pinned наверх и нарушения принципа нижней доступности. Папки отображать как drill-down фильтр; внутри них также старые сверху, новые снизу. Строка чата 46–52 при обычном тексте (Android не ниже 48), заголовок до двух строк, активная строка Bg.Selected; unread/running — небольшой смысловой индикатор.

Долгое нажатие строки: переименовать, закрепить/открепить, переместить в папку, метки, архивировать/вернуть, экспорт, поделиться, настройки чата, копировать/перенести в другой профиль, удалить. Мультивыбор включается отдельным пунктом; далее счётчик и пакетные действия, без desktop Ctrl/Shift и рамки мышью. Удаление — подтверждение с количеством; отмена архивации через snackbar.

Нажатие квадратной кнопки сразу создаёт обычный чат; временный режим доступен через меню заголовка нового чата без дополнительной постоянной кнопки. Временный чат — осознанное новое поведение из референса Venice: значок/подпись «Временный», не попадает в историю, черновик/вложения очищаются после завершения сессии. Это не обещание отсутствия хранения у провайдера. При переключении с непустого временного чата предложить сохранить либо закрыть. Для этапа 1 проверяется локальная семантика.

## GESTURE-01. Свайпы

Состояния Closed → Tracking → Open либо возврат в Closed. Начало разрешено на обычной поверхности ленты, а не только от самого края: владелец просит небольшой свайп пальцем. После 10 dp движения захватывать направление только если abs(dx) > 1.4×abs(dy). Вертикальный жест сразу отдаётся ленте. Отслеживание показывает sidebar под пальцем.

Открывать после отпускания при dx ≥64 dp либо скорости вправо ≥450 dp/s и dx ≥24 dp. Для закрытия симметричные значения влево. Ниже порога — возврат. Числа стартовые: уточнить на устройстве, сохранив короткий и предсказуемый жест. Завершение 180–220 ms ease-out; Reduce Motion — сразу без пружины. Резкое изменение направления до отпускания учитывает конечную позицию/скорость.

Не перехватывать жест внутри редактора, выделяемого текста, горизонтального кода/таблицы, картинки с pan/zoom, slider или bottom sheet. Первые системно зарезервированные краевые области не перекрывать, не запрашивать полный gesture exclusion. В закрытом чате одна кнопка sidebar остаётся альтернативой свайпу. В открытом sidebar возврат доступен через scrim с доступным именем «Вернуться в чат» или системный Back; не добавлять hamburger, крестик и отдельную стрелку одновременно. Если открыта клавиатура, начало уверенного свайпа скрывает её, но сохраняет draft/selection; закрытие sidebar не вызывает клавиатуру самопроизвольно.

Back сначала закрывает IME (по platform behavior), затем верхний sheet/dialog, затем sidebar, затем вложенную страницу настроек, затем настройки целиком. Исключить двойное срабатывание native Back + своего handler. Фокус после закрытия возвращается в элемент, открывший панель. Скринридер не читает затемнённый чат, пока sidebar/sheet открыт.

## SETTINGS-00 и редакторы

Настройки открываются отдельной полноэкранной страницей с заголовком и Back. Корневая страница — группы и 10 сохраняемых разделов с оригинальными цветными пиктограммами; вместо desktop-колонки навигации — переход на страницу раздела. Перечень и действия — docs/03. На широком экране допустима master-detail структура.

Строка настройки: слева название и описание, справа значение/переключатель/chevron. Минимум 56, высота auto. Сложные редакторы (промпт, инструкция, ключ) full-screen; простые варианты bottom sheet. Для switch изменения сохраняются сразу; для редактора есть «Сохранить» и «Отмена». Back с несохранённым текстом предлагает сохранить/отбросить/остаться. Ошибка показывается возле поля; клавиатура не закрывает нижнее действие. Пароли и ключи маскируются.

## Общие состояния

Поддержать пустые данные, skeleton/loading без мигания всей страницы, offline, stale, permission denied, нехватку места, повреждённый импорт, прерванный stream, превышение контекста, несовместимое вложение, неверный ключ, лимит расходов. Ошибка объясняет действие пользователя и сохраняет черновик. Raw JSON/stacktrace/tool payload не показывается как ответ модели. Диагностика доступна в «О программе», без секретов.

Demo harness должен воспроизводить каждое состояние без сети. При остановке/возврате из background сохранить draft и снимок ответа; после потери процесса показывать «Ответ прерван», не перезапускать платный запрос автоматически.
