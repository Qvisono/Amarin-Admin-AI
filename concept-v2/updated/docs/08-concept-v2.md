# 08. Концепт 02 — исправленная компоновка

13 октября 2026. Эта редакция заменяет первый, отклонённый владельцем концепт чата и sidebar. Актуальный визуальный эталон — `design/mobile-concept.html` и `design/mobile-screens.png`. Первая схема хранится только в `design/archive/v1/`, не использовать её для реализации.

## Решение

Ввод — единая невысокая поверхность: текст сверху, элементы управления одной строкой снизу. Внутри toolbar слева прикрепление, затем короткая плашка модели с effort, справа компактная пара показателей и отправка. Убрать отдельную нижнюю строку статистики, широкую плашку «Модель чата / Размышление: высокий», декоративные разделители и фиксированную высоту 178.

Sidebar — список, привязанный к нижней части свободной области. Под ним поиск и **квадратная кнопка нового чата 1:1 справа от поиска**, а последней строкой аватар/имя и шестерёнка. Нет отдельной широкой кнопки «Новый чат», большой карточки «Локальный профиль», дублирующей кнопки меню, крестика и боковой стрелки закрытия.

## Геометрия поля ввода

| Элемент | Концепт при обычном размере текста |
|---|---|
| Внешний отступ слева/справа | 12 dp |
| Внешний отступ снизу | 12–14 dp + фактический системный inset |
| Скругление | 26 dp |
| Внутренний padding | сверху 10; слева/справа 8; снизу 8 |
| Поле текста | 43 dp для одной строки; font 16, line-height 23 |
| Нижний ряд | 44 dp iOS; 48 dp Android |
| Высота пустого composer | около 107 dp iOS / 111 dp Android, без safe area |
| Прикрепление | видимый plus 23; прозрачная область 44/48 |
| Плашка модели | высота 34; содержимое по ширине, не растягивать фон |
| Имя/effort | `Kimi K2 · High`, одна строка, без длинной подписи |
| Показатели | общая область 58×44/48; 2 короткие строки: `○ 3k/128k` и `$12.40` |
| Отправить | видимый круг 38; область 44/48; arrow 22 |

Ряд представляет собой `attachment / minmax(0, model area) / metrics / send` с промежутками 3–4 dp. Свободное место остаётся между плашкой модели и показателями, а не превращает плашку в огромную кнопку. В HTML-эталоне модель занимает ширину по содержимому.

Показатели — **одна область нажатия**, открывающая общий sheet «Контекст и баланс». Внутри него показатели разделены и подробно подписаны. Не накладывать два маленьких touch target друг на друга. Доступное имя сразу сообщает оба значения. Визуальная компактность не требует скрытия чисел за одной иконкой.

На 320 dp logo модели можно убрать, чтобы сохранить имя и effort; logo остаётся в picker. Более длинные имена сокращаются многоточием только в имени, не в effort и не в балансе. При 200% текста сделать осмысленный перенос toolbar, а не сжимать шрифт до нечитаемого. Дополнительный ряд в accessibility-режиме допустим, но не является стандартным видом.

Однострочное поле не резервирует высоту пяти строк. Высота растёт только с фактическим текстом; максимум 5 строк, затем внутренний scroll. Вложения появляются только после выбора. Disabled Send приглушён; при тексте — светлый круг, при генерации — stop в том же месте. Никаких постоянных подписей/панелей вокруг поля.

## Sidebar

Ширина `min(360, viewport − 44)`; справа остаётся видимая затемнённая часть чата. Не рисовать стрелку на этом остатке. Вверху — небольшой исходный знак и Amarin; это не скрытая вторая кнопка создания чата. Ниже компактный «Все чаты» с фильтрами папок/архива. История занимает гибкую область с пустым пространством сверху, новыми чатами внизу. При длинной истории использовать обычный scroll и bottom anchor, не CSS-переворот и не flex-end, делающий начало переполненного списка недоступным.

Строки истории 46–52 dp для обычного текста, выделение только у активной, лёгкая иконка чата. Новейший чат сразу над поиском. Между списком и поиском около 12 dp.

Поиск и новый чат находятся в одном grid-ряду: `* / 44`, промежуток 8, обе высоты 44 (Android `* / 48`, обе 48). Квадратная кнопка всегда 1:1. В поиске значок и короткий placeholder «Поиск»; полное доступное название «Поиск по чатам». Поле не закрывает кнопку при вводе.

Под ними divider с отступом 12; профиль 44–48 в высоту, аватар 32, имя 14–15. Шестерёнка справа 44/48. Без отдельной внешней карточки и без постоянно повторяемой подписи «Локальный профиль». Этот статус показывается при открытии профиля.

Нажатие «Новый чат» сразу создаёт обычный чат. Временный режим доступен в меню заголовка пустого нового чата; не нужен второй значок/стрелка возле кнопки создания. Долгое нажатие может быть ускорением, но не единственным способом доступа.

## Навигация без дублирования

- Закрытый чат: одна кнопка sidebar слева сверху; название открывает действия чата. Правая часть header пустая. Нет фиктивных системных индикаторов.
- Открытый sidebar: свайп влево / tap по видимой части чата / системный Back. Крестик, дублирующий hamburger и отдельная стрелка закрытия отсутствуют. Для screen reader видимая часть чата имеет доступное действие «Вернуться в чат».
- Настройки: одна кнопка Back слева, возвращающая в sidebar; не добавлять вторую «Закрыть» снизу.
- Selection sheet: один «Применить» для фиксации выбора; отмена через внешний scrim или Back. Информационный sheet не нуждается в «Применить», «Сохранить» и двух кнопках закрытия.
- Подтверждение удаления — отдельный осмысленный диалог, где «Отмена» не считается дублем навигации.

Нативные статусная строка и home indicator принадлежат ОС. Приложение учитывает их insets; **не рисует** свои заменители. На концепте показывается область приложения без поддельных батарей, полосок и времени.

## Цвет и типографика

В концепте тёмная нейтральная палитра с лёгким холодным оттенком: фон #0F1114, sidebar #101215, composer #191C20, плашка модели #24282D, selected chat #24282E; primary #E7E9ED, body #D4D7DC, muted #95999F. Это mobile-палитра данного концепта; остальные темы Amarin продолжают работать через семантические ресурсы. Не вшивать эти цвета напрямую во все controls.

Плашка модели 13, effort/metrics 11–12 при обычном font scale; обязательная информация доступна крупно в sheet. Основной текст 16, sidebar 14–15. Визуальный баланс проверять на физическом размере экрана; не увеличивать все видимые кнопки до их touch target.

Использованы оригинальные знак приложения, Kimi и шестерёнка из исходников; иконки разделов настроек исходные. Простые служебные контуры макета (menu, plus, search, new-chat) — проектные обозначения; в итоговой Avalonia-сборке сопоставить их с оригинальными геометриями по icon-map, не считать их завершённым переносом всего набора.

## Что проверено

Локальный HTML-макет отрисован в Chromium/Edge на ширинах 320/360/390/430; измерены composer и границы toolbar, проверены отсутствие наложений, квадрат нового чата, поиск, открытие sidebar, новый чат, локальная отправка текста, выбор effort, sheet контекста/баланса и вход в настройки. Результаты — `design/layout-checks.json`; изображения — `design/previews/`.

Это концепт, не Avalonia-приложение. Он не доказывает работу native IME, 200% dynamic type, TalkBack/VoiceOver, реальных запросов, iOS/Android или долгой виртуализированной истории. Фильтры/профиль/настройки в нём показывают навигационную форму, не полноценную бизнес-логику. Эти проверки остаются в docs/06. Не выдавать preview-кнопки за реализованный продукт.
