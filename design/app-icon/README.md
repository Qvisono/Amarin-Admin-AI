# Значок: лис

Варианты нового значка Amarin Admin AI. Красный, плоский, 2D: милый лис с опущенными ушками
и приоткрытым ротиком. Фон прозрачный, подложки нет: значок кладётся прямо на окно программы.
Из трёх вариантов выбирается один.

![Три варианта](overview.png)

|   | Вариант | Файлы |
|---|---|---|
| A | «Ушки»: большие блестящие глазки | `fox-a.svg`, `fox-a.ico` |
| B | «Зажмурился»: глазки дужками | `fox-b.svg`, `fox-b.ico` |
| C | «Капсулы»: глаза-капсулы, самый лаконичный | `fox-c.svg`, `fox-c.ico` |

Основа у всех трёх общая: красная голова, белая зубчатая шерсть на щеках в красной кайме,
ушки прижаты к голове и опущены вниз-наружу, кончики ушей тёмные, ротик приоткрыт.

Подробный лист с настоящими размерами, видом в боковой колонке и на панели задач и сеткой
полей: [preview.png](preview.png).

## Отступы

Рамка рисунка ровно квадратная и стоит по центру, поэтому поля одинаковые со всех четырёх
сторон: 64 из 1024, на 256 px это 16 px. У нынешней «A» поля разные: слева
20 px, справа 31 (на 256).

## ICO

Кадры 256, 128, 96, 64, 48, 40, 32, 24, 20 и 16 px. Каждый нарисован из вектора под свой размер,
а не ужат из большого: от 40 px полный рисунок, на 24-32 px без тени под ушами и язычка, на
16-20 px остаются силуэт, шерсть, уши, глаза и нос. Кадры от 64 px хранятся как PNG, мелкие как
32-битные BMP; порядок от крупного к мелкому.

## Как пересобрать

Рисунок задан кодом в `src/fox_icons.py` (точки контуров, цвета, уровни детализации), всё
остальное собирается из него:

    pip install skia-pathops numpy pillow
    npm install -g playwright && npx playwright install chromium
    python3 design/app-icon/src/make.py

Скрипт перезаписывает SVG, ICO и оба листа в этой папке. Контуры строятся сплайнами Хобби
(`src/hobby.py`), как в METAFONT: кривая проходит через заданные точки без бугров. SVG на выходе
состоят только из залитых путей, без масок и обводок, поэтому контуры переносятся в XAML как есть.
