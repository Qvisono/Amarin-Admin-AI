# Значок: лис

Варианты нового значка Amarin Admin AI. Плоский красный, как нынешняя «A»: только её оттенки,
без белого и чёрного. Милый лис с опущенными ушками и приоткрытым ротиком. Фон прозрачный,
подложки нет: значок кладётся прямо на окно программы. Из трёх вариантов выбирается один.

![Три варианта](overview.png)

|   | Вариант | Файлы |
|---|---|---|
| A | «Глазки»: оттенки красного, большие блестящие глазки | `fox-a.svg`, `fox-a.ico` |
| B | «Зажмурился»: оттенки красного, глазки дужками | `fox-b.svg`, `fox-b.ico` |
| C | «Один красный»: один цвет, щёки и глазки прорезаны, как штамп | `fox-c.svg`, `fox-c.ico` |

Основа у всех трёх общая: круглая голова, на щеках по две пряди шерсти, уши опущены и отведены
в стороны (60° от вертикали), кончики ушей тёмные, ротик «о» приоткрыт.

Цвета A и B взяты у «A»: основной `#D81F2D`, тёмный `#9E1826` (кончики ушей), средний `#C4192B`
(наружная сторона уха), светлый `#E2525D` (щёки), розовый `#EB8597` (блики, румянец, язычок) и
самый тёмный `#6E0F1A` (глаза, нос, ротик). У C один цвет, `#D81F2D`: щёки прорезаны насквозь,
поэтому на светлом фоне они светлые, на тёмном тёмные, а силуэт держит красная кайма.

Подробный лист с настоящими размерами, видом в боковой колонке и на панели задач и сеткой
полей: [preview.png](preview.png).

## Отступы

Рамка рисунка ровно квадратная (858 × 858 из 1024) и стоит по центру, поэтому поля одинаковые
со всех четырёх сторон: 64 из 1024, на 256 px это 16 px. Квадратность сверяет `make.py`: правка
пропорций, которая её ломает, останавливает сборку. У нынешней «A» поля разные: слева 20 px,
справа 31 (на 256).

## ICO

Кадры 256, 128, 96, 64, 48, 40, 32, 24, 20 и 16 px. Каждый нарисован из вектора под свой размер,
а не ужат из большого: от 40 px полный рисунок; на 24-32 px без румянца, второго блика и двух
тонов уха, глаза и ротик крупнее; на 16-20 px остаются силуэт, щёки, кончики ушей, глаза и нос,
а кайма вокруг щёк шире, чтобы не пропадала. Все уровни ставятся по рамке полного рисунка, так
что кадры разных размеров не разъезжаются. Кадры от 64 px хранятся как PNG, мелкие как 32-битные
BMP; порядок от крупного к мелкому.

## Как пересобрать

Рисунок задан кодом в `src/fox_icons.py` (точки контуров, цвета, уровни детализации), всё
остальное собирается из него:

    pip install skia-pathops numpy pillow
    npm install -g playwright && npx playwright install chromium
    python3 design/app-icon/src/make.py

Скрипт перезаписывает SVG, ICO и оба листа в этой папке. Голова строится сплайнами Хобби
(`src/hobby.py`), как в METAFONT: кривая проходит через заданные точки без бугров; уши строятся листьями
из двух дуг. SVG на выходе состоят только из залитых путей, без масок и обводок, поэтому контуры
переносятся в XAML как есть.
